# Pendientes del usuario

Lo que **solo puede hacer el usuario** (o la oficina, a pedido suyo): decisiones de negocio, credenciales y paneles externos (apisperu, Gmail, somee, Onway, UptimeRobot, cron-job.org), datos o documentos que hay que conseguir y pruebas con un conductor o un celular real. Claude no puede hacerlo: no entra a esos paneles, no tiene esos datos y no decide por el negocio. Cuando el usuario resuelve uno, Claude hace lo que siga (si hace falta) y borra el ítem; si la decisión queda como regla, va a `docs/DECISIONES_NEGOCIO.md`.

Prioridad: A = riesgo de datos, dinero o seguridad, o bloquea el uso real; B = valor claro; C = menor. Las mejoras de código están en `docs/PLAN_MEJORAS_SGV.md` (`M-`), los datos por corregir en `docs/DATOS_POR_CORREGIR.md` (`D-`) y las pruebas en `docs/PRUEBAS_PENDIENTES.md` (`P-`).
